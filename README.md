# Payday — Accounting Payroll

숫자만 보여주는 대신 **설명하고, 점검하고, 미리 보여주는** 급여(Payroll) 관리 웹사이트입니다. React + TypeScript + Vite 기반입니다.

## 시작하기

Node.js 22 이상이 필요합니다.

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:5173 을 엽니다.

## 배포 (GitHub Pages)

`main`에 푸시하면 `.github/workflows/deploy.yml`이 자동으로 빌드·배포합니다.
주소: https://gunbinlim1.github.io/Accounting/

처음 한 번은 저장소 **Settings → Pages → Build and deployment → Source**를
**GitHub Actions**로 설정해야 합니다.

> ⚠️ 공개 사이트입니다. 실제 직원 정보는 넣지 마세요.

## 고객 포털 데모

회계법인 고객(레스토랑)이 직원·근무·팁을 입력해 제출하면, 회계법인이 검토·처리·납부·신고까지 하는 흐름입니다.
기획 전체는 기획서 문서에 정리되어 있습니다.

```
고객: 로그인(+2단계 인증) → W-4·I-9 업로드(자동 입력) → 근무·팁·Fringe 입력(엑셀·CSV 가져오기)
      → 회계법인에 제출 (🔒 잠김, 검토 전엔 취소 가능)
회계법인: 대기열 → 검토 → 수정 요청 또는 처리 완료
      → 지급(직접입금·인쇄 수표·고객 수표) + 급여명세서 이메일 + IRS 예치 일정 등록
      → 세금·신고 탭에서 납부 처리, 분기 941·C-3·FUTA 대조, W-2 미리보기
고객: 급여 내역·세금 안내 확인 / 직원: 직원 포털에서 급여명세서·W-2 열람
```

신고 방식: 회계법인이 **Reporting Agent(Form 8655)**로 고객 EIN에 대리 신고하고, 세금은 고객 계좌에서 인출해
등록된 대행 채널로 납부합니다 (공동고용 PEO 방식 아님).

| 데모 계정 (로그인 화면에서 클릭) | 역할 | 이번 회차 상태 |
|---|---|---|
| Seoul Garden BBQ · Grace Kim | 고객 | 작성 중 |
| Taqueria El Sol · Luis Hernández | 고객 | 제출됨 (TWC 위임 미서명) |
| Pho Bellaire · Linh Tran | 고객 | 수정 요청 (8655 위임 미서명) |
| Maria Lopez | 직원 포털 | 급여명세서·W-2 |
| Demo CPA · Jordan Lee | 회계법인 | 전체 고객사 대기열 |

인증 코드는 아무 숫자 6자리. 명령 팔레트(⌘K)의 "데모 데이터 초기화"로 처음 상태로 돌릴 수 있습니다.
직원 등록 화면의 "데모용 W-4/I-9 샘플 PDF"로 자동 입력을, 급여 실행의 "연습용 샘플 CSV"로 가져오기를 체험할 수 있습니다.

> ⚠️ 데모는 로그인·데이터가 모두 브라우저(localStorage)에 있습니다. 실제 고객 데이터를 받기 전에
> 서버 인증(MFA), 고객사별 데이터 분리, SSN·계좌 암호화, 비공개 호스팅이 필요합니다.

## 주요 기능 — 텍사스 레스토랑 템플릿

| 화면 | 내용 |
|---|---|
| **홈** | 다음 급여일 D-day, 급여 입금·팁·IRS 예치(+TWC/FUTA)·**45B 팁 크레딧** 타일, "급여 $1은 어디로?" 그래프, 941/940/W-2/TWC C-3/8027 기한 |
| **직원 등록** | 직무 템플릿(서버·바텐더·버서·러너·호스트·라인 쿡·디시워셔·매니저) → 개인 정보 → **W-4** → **I-9** → 확인. 오른쪽에 예상 급여 실시간 미리보기 |
| **급여 실행** | 정규·OT 시간, 현금 팁(신고)·카드 팁 입력 → 자동 점검 → 승인. 팁 포함 시급이 $7.25 미만이면 자동 보전 |
| **급여명세서** | 지급/공제 항목별 쉬운 설명, 회사 부담(SS·Medicare·FUTA·TWC), 45B 크레딧, 2026 W-2 보고용 팁·OT 프리미엄 |
| **직원 목록** | W-4 상태, I-9 상태(3영업일 기한, 취업허가 만료 90일 전 알림) 배지, "서류 확인 필요" 필터 |
| **시뮬레이터** | 시급 인상·OT·시간당 팁·401(k)를 바꿔 직원 수입과 레스토랑 인건비 비교 |
| **공통** | ⌘K / Ctrl+K 명령 팔레트, 한국어/English, 다크 모드, 모바일 하단 탭 |

### W-4 (2020 이후 양식)
신고 상태(Step 1c), 복수 직장(Step 2), 부양가족 공제(Step 3, 자녀 $2,200·기타 $500 계산 도우미), 기타 소득·추가 공제·회당 추가 원천징수(Step 4a–c), 면세(Exempt), 서명일.
W-4가 없으면 IRS 규정대로 Single·조정 없음으로 원천징수합니다.

### I-9
Section 1(시민권/영주권/취업허가 상태, A-Number, 취업허가 만료일, 서명일)과
Section 2(List A 1개 또는 List B+C, 서류명·발급기관·번호·만료일, 완료일)를 기록합니다.
**보안을 위해 SSN·A-Number·서류 번호는 뒤 4자리만 저장**합니다.

## 세금 계산 규칙 (2026, 텍사스)

| 항목 | 규칙 |
|---|---|
| 연방 소득세 | IRS Pub. 15-T 연간 퍼센트 방식 (2020+ W-4). 2026 표준공제 $16,100 / $32,200 / $24,150, 세율 구간 Rev. Proc. 2025-32 |
| Social Security | 6.2% (직원·회사 각각), 연 $184,500까지 — 팁 포함 |
| Medicare | 1.45% (직원·회사), 연 $200,000 초과분 직원 0.9% 추가 |
| 텍사스 주 소득세 | 없음 |
| TWC 실업세 | 회사만 부담, 첫 $9,000까지, 신규 고용주 2.7% (`sutaRate`를 TWC 통지 세율로 변경) |
| FUTA | 0.6%, 첫 $7,000까지 |
| 팁 직원 | 현금 시급 최소 $2.13, 팁 크레딧 최대 $5.12. OT 시급 = $7.25 × 1.5 − 팁 크레딧 ($5.755). 팁 포함 $7.25 미만이면 차액 보전 |
| 현금 팁 | 과세 대상이지만 이미 직원이 받았으므로 입금액에서 제외. 급여가 부족하면 FICA를 먼저 원천징수하고 남은 미징수액은 W-2 Box 12 A/B |
| 45B 크레딧 | 시간당 $5.15를 채우는 데 쓰인 팁을 제외한 팁에 대한 회사 FICA (Form 8846) |

> ⚠️ 2026 수치는 공개 자료로 확인했지만 IRS 원문과 직접 대조하지 못했습니다. 실제 급여 처리 전에
> IRS Pub. 15-T, SSA, TWC 공지와 대조하고 세무 전문가 검토를 받으세요.
> 연방 공휴일은 I-9 영업일 계산에 반영하지 않습니다. 레스토랑 직원 10명 초과 여부(Form 8027 대상)는 직접 판단하세요.

│   ├── federalWithholding.ts # W-4 기반 연방 소득세 (+ 테스트)

│   ├── compliance.ts         # I-9 기한·취업허가 만료, SSN 마스킹
