# Payday — Accounting Payroll

숫자만 보여주는 대신 **설명하고, 점검하고, 미리 보여주는** 급여(Payroll) 관리 웹사이트입니다. React + TypeScript + Vite 기반입니다.

## 시작하기

Node.js 22 이상이 필요합니다.

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:5173 을 엽니다.

## 배포 (GitHub Pages)

`main`에 푸시하면 `.github/workflows/deploy.yml`이 자동으로 빌드·배포합니다.
주소: https://gunbinlim1.github.io/Accounting/

처음 한 번은 저장소 **Settings → Pages → Build and deployment → Source**를
**GitHub Actions**로 설정해야 합니다.

> ⚠️ 공개 사이트입니다. 실제 직원 정보는 넣지 마세요.

## 주요 기능

| 화면 | 무엇이 다른가 |
|---|---|
| **홈** | 다음 급여일 D-day와 기간 진행률, 직원 실수령·IRS 예치액·회사 총 인건비, "급여 $1은 어디로?" 그래프, 신고 기한(941/940/W-2) 타임라인 |
| **급여 실행** | 근무시간 → 검토 → 승인 3단계 마법사. +/− 버튼과 "표준 80시간"·"지난번과 동일" 원클릭 입력. **자동 점검**(0시간, 표준 초과, 실수령액 ±15% 변동, SS 상한 도달, 401(k) 미가입)이 승인 전에 실수를 잡아 줌. 승인 후 할 일 목록과 급여명세서 인쇄 |
| **쉬운 말 급여명세서** | 공제 항목마다 "왜 빠지는지" 한 줄 설명, 회사 부담 세금과 총 인건비까지 표시 |
| **시뮬레이터** | 인상률·401(k)·초과근무 슬라이더로 실수령액과 회사 비용 변화를 즉시 확인, 401(k) 세금 절감 효과를 문장으로 설명 |
| **직원** | 카드형 목록, 검색·필터, 슬라이드 패널로 추가·수정, 퇴사/복직 처리 |
| **공통** | ⌘K / Ctrl+K 명령 팔레트, 한국어/English 전환, 다크 모드, 모바일 하단 탭 |

데이터는 브라우저(localStorage)에만 저장됩니다. 명령 팔레트의 "데모 데이터 초기화"로 처음 상태로 돌릴 수 있습니다.

## 구조

```
src/
├── config/payrollConfig.ts   # 세율, 급여 일정, 표준 근무시간
├── lib/
│   ├── payroll.ts            # 급여 계산 (+ 테스트)
│   ├── checks.ts             # 승인 전 자동 점검 규칙
│   ├── schedule.ts           # 급여일·신고 기한 계산 (+ 테스트)
│   └── segments.ts           # 급여 구성 그래프 항목/색
├── store.tsx                 # 직원·근무시간·급여 기록 상태 (localStorage)
├── prefs.tsx                 # 언어·테마 설정
├── components/               # 레이아웃, 명령 팔레트, 그래프, 급여명세서, 점검 목록
└── pages/                    # 홈, 급여 실행, 직원, 시뮬레이터
```

## 급여 계산 규칙

- 총급여: 연봉 ÷ 연간 지급 횟수, 또는 시급 × 시간 (초과근무 1.5배)
- 401(k) 세전 공제 후 금액에 연방·주 원천징수 적용
- Social Security 6.2% (연간 상한 적용), Medicare 1.45% — 총급여 기준, 회사도 같은 금액 부담
- 급여 일정: 격주 금요일 (`companySchedule`에서 변경)

> ⚠️ 연방·주 원천징수는 **임시 정률(placeholder)** 입니다. 실제 급여 지급 전에
> IRS Publication 15-T와 해당 주의 원천징수 표로 교체하세요.
> 요율과 상한액은 `src/config/payrollConfig.ts`에서 매년 갱신합니다.
